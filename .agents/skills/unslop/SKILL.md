# Natural prose

Read the actual passage before rewriting. Pattern searches can locate repetitive phrases but cannot judge voice, meaning or context. The translation skill owns source accuracy and character voice; this pass polishes the English within those decisions.

## Translated material

Keep the source meaning, register, emotional subtext and deliberate repetition. Do not add personal opinions, jokes, reactions or explanatory details to make a passage feel more human. Preserve names and the project's terminology choices.

Read dialogue aloud for spoken rhythm. Replace stiff calques and unnecessary filler when they do not carry character or source meaning. Avoid making every speaker sound equally casual or equally polished. Formal, hesitant, blunt and awkward speech can be intentional.

Use natural English sentence structure without forcing every sentence into active voice. Preserve passive phrasing, fragments, repetition and punctuation when they serve the source. Do not trade accuracy for a shorter balloon; return a fit problem to the coordinator and lettering stage.

Use no em dashes in new translations. Rewrite the sentence naturally instead of deleting punctuation mechanically. Preserve a line byte for byte when the user explicitly retained that approved wording. Keep intentional translation line breaks and formatting separate from Markdown source wrapping.

## Guides and user-facing prose

State the concrete action or result first. Prefer familiar words, short connected sentences and specific examples that help the user proceed. Remove puffery, canned transitions, vague claims, repeated summaries and unnecessary qualifiers. Use lists for parallel actions or comparisons, not as a substitute for every paragraph.

Keep each prose paragraph on one Markdown source line. Preserve headings, real list structure, tables, fenced code and intentional text breaks. Do not introduce arbitrary hard wraps or manual indentation. Check that the revised wording still describes the actual workflow and current controls.

## Final read

Read the changed passage again for meaning and flow. Check adjacent lines, voice and terminology. For guides, verify referenced actions and paths. Do not rewrite already natural text merely to demonstrate an editing pass.
